操作說明

  1. 可用關鍵字、法規模組與業態篩選規則。
  2. 「現行規定」顯示目前已生效的整併適用條件；「歷史沿革」查看過去已實施階段；「未來實施」只顯示已正式公告但尚未生效的規定。

  4. 「匯出目前查詢CSV」會匯出目前篩選後的全部結果，不受分頁影響。
